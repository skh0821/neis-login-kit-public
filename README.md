# 나이스 로그인 키트

바탕화면 글자 하나로 **나이스 · 에듀파인 · 업무포털에 로그인**해 주는 교사용 도구입니다.

> 이 키트는 연수에서 소개된 [neis-automation-kit](https://github.com/workcalmkite-hue/neis-automation-kit)(MIT 라이선스)을 바탕으로,
> 로그인 기능을 중심으로 다듬어 정리한 것입니다. 좋은 키트를 만들어 나눠 주신 강사님께 감사드립니다.

## 하는 일

| 글자 | 누르면 |
|---|---|
| 나이스 | EVPN 연결(필요할 때) → 인증서 로그인 → 나이스 첫 화면 |
| 에듀파인 · 문등대 | 업무포털 인증서 로그인 → K-에듀파인 첫 화면 · 문서등록대장 |
| 업무포털 | 업무포털 첫 화면 (에듀파인과 같은 창의 다른 탭) |
| 상벌점 · 문자 | 리로스쿨 로그인 (상벌점은 미보관 학번 채우기 도우미 포함) |

- 누르면 본인을 확인합니다. **맨 처음 한 번 «Windows Hello(지문·얼굴·PIN)» 와 «잠금 비밀번호» 중에서 고르고**, 그다음부터는 고른 방식으로만 확인합니다.
  지문·얼굴 장치가 없는 PC 는 잠금 비밀번호를 고르면 됩니다. 한 번 확인하면 30분 동안 다시 묻지 않고, 오른쪽 클릭 «지금 잠그기» 로 바로 끝낼 수 있습니다
- 잠금 비밀번호는 글자 그대로 저장하지 않습니다 (소금 친 해시만, Windows 암호화). 5번 틀리면 5분 동안 잠깁니다.
  방식은 설정 창 [계정 관리] → [본인 확인 방식 바꾸기] 에서 바꾸고, 확인이 아예 안 되면 `본인확인_다시고르기.cmd`
- 로그인하는 동안 크롬은 작업표시줄에 내려가 있어 **다른 창에서 하던 일을 계속하셔도 됩니다.** 다 되면 화면이 앞으로 나옵니다
- EVPN 으로 들어갔으면, 열린 창을 모두 닫을 때 EVPN 도 끊습니다

## 비밀번호는 어디에

- 인증서 암호 · EVPN 비밀번호 · 리로스쿨 비밀번호는 **Windows 자격 증명 관리자(금고)** 에만 둡니다. 파일 · 환경 변수 · 클립보드에 남기지 않습니다
- 로그인 화면의 주소가 진짜 나이스 · 업무포털 · EVPN 주소인지 확인한 **뒤에만** 금고를 엽니다
- 금고 안 항목 이름은 **사람마다 무작위**로 정해집니다 (처음 쓸 때 만들어 암호화된 개인 설정에 둡니다). 이 코드를 읽어도 각자의 항목 이름은 알 수 없습니다
- 개인 설정(인증서 이름 · EVPN 아이디 등)은 Windows 암호화(DPAPI)로 저장합니다
- 같은 Windows 계정으로 실행된 프로그램은 금고를 열 수 있습니다. **출처를 모르는 프로그램은 실행하지 마시고, 자리를 비울 때는 `Win` + `L`** 로 잠가 주세요

## 설치

처음이면 [시작하기.md](시작하기.md) 를 보세요. 요약:

1. 이 저장소를 받습니다 (초록색 [Code] → Download ZIP, 또는 `git clone`)
2. 폴더에서 PowerShell 로 `.\setup.ps1` — 파이썬 · 패키지 · 브라우저 도구를 깝니다
3. `.\.venv\Scripts\python.exe secure_settings.py` — 지역 · 접속 방식 · 인증서 · EVPN 을 넣습니다 (비밀번호는 전용 짧은 창에서)
4. `widget\library-demo\install_text.cmd` 더블클릭 — 글자 위젯 설치 · 시작 메뉴 «글자 위젯» · 로그인하면 자동 시작

## 알아 둘 것

- Windows 11 · 크롬 · **서울(EVPN 포함)** 에서만 시험했습니다. 다른 지역은 주소 규칙은 같지만 직접 확인하지 않았습니다
- 나이스 · 에듀파인은 정부 시스템입니다. 이 키트는 브라우저를 프로그램으로 조작해 로그인을 대신합니다 — **본인 계정 · 본인 인증서로 본인 업무에만** 쓰세요
- 문제가 생기면 `widget\library-demo\build\desktop-text.log` 에 단계별 기록(값 없음)이 남습니다
